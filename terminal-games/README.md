# Terminal Games Collection

Welcome to the C# Terminal Games collection! These are complete, playable games that run in your terminal/console. Perfect for learning C# while having fun!

## 🎮 Available Games

### 1. Number Guessing Game
**Difficulty**: Beginner  
**Description**: The computer picks a random number, and you try to guess it with hints!  

**What you'll learn**:
- Random number generation
- Loops and conditionals
- User input validation
- Basic game loop

**How to play**:
```bash
cd NumberGuessingGame
dotnet run
```

## 🚀 Quick Start

### Prerequisites
- .NET SDK installed (check with `dotnet --version`)
- A terminal/command prompt

### Running Any Game

1. Navigate to the game directory:
   ```bash
   cd [GameName]
   ```

2. Run the game:
   ```bash
   dotnet run
   ```

That's it! The game will start immediately.

## 📚 Learning Path

We recommend playing and studying the games in this order:

1. **Number Guessing Game** - Start here! Learn basic loops and input.
2. **Hangman** - Practice strings and lists.
3. **Tic-Tac-Toe** - Master arrays and game logic.
4. **Text Adventure** - Explore complex state management.

## 🐛 Common Issues

### "dotnet: command not found"
- Install the .NET SDK from https://dotnet.microsoft.com/download

### Game doesn't display colors properly
- Try a different terminal (Windows Terminal, iTerm2, etc.)
- Colors work best on modern terminal applications

### Build errors
- Make sure you're in the correct game directory
- Run `dotnet restore` to restore dependencies
- Check that your .NET SDK version is up to date
